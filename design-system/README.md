# Design system

The FQuiz design guidance is under `fquiz/`. Start with [`MASTER.md`](./fquiz/MASTER.md), then check for a page-specific guide under [`fquiz/pages/`](./fquiz/pages/).

Use the shared `@fquiz/ui` package and [`docs/DESIGN_THEME.md`](../docs/DESIGN_THEME.md) as implementation references. If the master or a page guide makes a measurable accessibility or contrast claim, verify it against the current tokens and tooling before treating it as established evidence.
