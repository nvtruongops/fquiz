# Admin routes

This directory contains the Admin App Router pages and API routes. Route handlers own HTTP boundary concerns; reusable data and authorization logic belongs in `lib/` or a shared package.

- Check [`docs/DESIGN_ROUTES.md`](../../../docs/DESIGN_ROUTES.md) for the route catalog.
- Check [`docs/API.md`](../../../docs/API.md) for documented request and response contracts.
- Update those references when route behavior or public contracts change.
