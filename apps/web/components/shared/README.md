# Shared Web components

This folder contains presentation building blocks used across Web features, including UI primitives, authentication components, providers, and reusable interaction helpers.

- `ui/`: app-level UI components.
- `auth/`: authentication UI.
- `providers/`: React context providers.
- `gsap/`: animation wrappers, where present.
- `selection/`: text-selection interactions, where present.

The shared package at [`packages/ui`](../../../../packages/ui/README.md) is the source for components intended for both applications. Keep this folder for Web-specific composition and adapters.
