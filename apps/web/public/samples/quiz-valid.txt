Question 1:
Question: What is the primary function of an operating system kernel?
A. Managing system resources and hardware communication
B. Compiling high-level programming code into machine instructions
C. Rendering graphical user interfaces in a web browser
D. Designing relational database schemas
Answer: A
Explanation: The kernel is the core component of an operating system responsible for managing CPU, memory, and hardware device interactions.

Question 2:
Question: Which of the following are examples of non-relational (NoSQL) databases?
A. PostgreSQL
B. MongoDB
C. Redis
D. SQLite
Answer: B, C
Explanation: MongoDB (document-based) and Redis (key-value store) are NoSQL databases, whereas PostgreSQL and SQLite are relational SQL databases.

Question 3:
Question: Which HTTP status code signifies that a requested resource was not found on the server?
A. 200 OK
B. 401 Unauthorized
C. 403 Forbidden
D. 404 Not Found
Answer: D
Explanation: HTTP 404 Not Found indicates that the origin server could not find a current representation for the target resource.
