# `@fquiz/auth`

Shared authentication and request-security helpers used by the applications. Source modules cover JWT handling, cryptography, CSRF, rate limiting, role checks, and auth wrappers.

Check `package.json` and `src/index.ts` for the supported package entry point. Keep app-specific redirects and UI outside this package. See [`docs/SECURITY.md`](../../docs/SECURITY.md).
